# Checklist: Cambio de Contraseña y Perfil

- [ ] Cambio de contraseña funciona con contraseña actual correcta
- [ ] Cambio de contraseña falla con contraseña actual incorrecta
- [ ] Nueva contraseña ≥ 8 caracteres validada
- [ ] Contraseña almacenada con bcrypt
- [ ] Sesiones invalidadas después del cambio
- [ ] Perfil actualizado en users.profile
- [ ] Avatar subido y accesible por URL
- [ ] Todas las operaciones registradas en user_activity_logs
