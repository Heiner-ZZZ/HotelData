# Especificación: Amenities, Imágenes y Contenido Multimedia

**Versión**: 1.1 | **Estado**: Actualizado | **Última actualización**: 2026-06-21

**Casos de uso TA07**: CU-O21 (Actualizar amenities, imágenes y contenido), CU-O37 (Gestionar contenidos multimedia con geolocalización)

## 1. Objetivo
Gestionar amenities, imágenes y contenido multimedia (fotos, videos) de propiedades, incluyendo geolocalización del contenido.

## 2. Contexto
Este spec fue actualizado para incluir la gestión de contenido multimedia geolocalizado (anteriormente CU-O37) junto con los amenities e imágenes tradicionales.

## 3. Actores
| Actor | Descripción |
|-------|-------------|
| Marketing hotelero | Actualiza amenities, imágenes y contenido geolocalizado |

## 4. Requisitos funcionales
| ID | Requisito |
|----|-----------|
| RF-001 | Gestionar amenities desde catálogo |
| RF-002 | Subir y eliminar imágenes (JPEG/PNG, máx 5MB) |
| RF-003 | Subir contenido multimedia geolocalizado (fotos/videos) |
| RF-004 | Geolocalizar contenido arrastrando marcador en mapa |
