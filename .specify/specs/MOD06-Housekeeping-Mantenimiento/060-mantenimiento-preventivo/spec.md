# Especificación: Programar Mantenimiento Preventivo y Correctivo (Táctico)

**Versión**: 1.0 | **Estado**: Draft | **CU TA07**: CU-T15

## 1. Objetivo
Programar y dar seguimiento al mantenimiento de habitaciones, minimizando interrupciones y prolongando vida útil.

## 2. Actores
| Actor | Descripción |
|-------|-------------|
| Gerente de hotel | Programa y supervisa mantenimiento |

## 3. Requisitos funcionales
| ID | Requisito |
|----|-----------|
| RF-001 | Programar mantenimiento recurrente o puntual |
| RF-002 | Bloquear disponibilidad durante mantenimiento |
| RF-003 | Registrar ejecución con observaciones |
| RF-004 | Dashboard de cumplimiento de mantenimiento |
