# Roles

## Admin

El admin puede consultar todas las vistas de HotelData Hub, administrar `system_catalogs` y revisar auditoria de ejecuciones ETL y busquedas.

## Usuario normal

El usuario normal puede consultar dashboard, registros, calidad, colecciones, empresa y problemas.

No puede modificar `system_catalogs` ni ejecutar el pipeline ETL.

## Regla clave

Los roles pertenecen a la capa web y no modifican el flujo ETL principal.
